CAPABILITIES

Features Designed for Developers

Simplifying Git workflows so you can focus on writing great code.

One-Click Auto Push

Automatically scans modified, added, and deleted files, crafts a timestamped summary message, and pushes to GitHub instantly.

  • Automatic file staging & diff scanning
  • Timestamped update commit messages
  • Auto-push to GitHub remote origin

Commit Undo & Rollback

Visual timeline of commit history with single-click options to revert commits safely or reset repository state.

  • Soft Undo: Creates inverse commit while keeping local edits
  • Hard Reset: Restores repository to chosen commit or URL
  • Paste target commit hash for instant rollback

Semantic Version Bumper

Manage software version tags easily with automated semantic version incrementing.

  • Patch (+0.0.1), Minor (+0.1.0), and Major (+1.0.0) options
  • Auto-creates Git annotated release tags
  • Pushes tags directly to GitHub

Developer Power Tools

Essential utilities for daily software engineering workflows built right into the app.

  • Branch Manager: Create, switch, and delete branches
  • Stash Manager: Save and pop uncommitted changes
  • .gitignore Generator for Python, Node, C++, Java & Go
SELF-ANALYSIS ENGINE

Deep Workspace & Git Inspection

Drop GitHub Easy Push into any folder to automatically analyze repository structures, parent lineage, and security rules.

01

Commit Lineage Mapping

Inspects your Git commit tree to display exact parent-child commit lineage ("which commit was committed to which"), authors, and timestamps.

02

.gitignore Protection Audit

Audits your .gitignore rules to ensure sensitive files like .env, node_modules/, and build/ are safely protected before pushing.

03

Sync Health & Divergence

Calculates exact commit divergence between your local branch and remote GitHub origin (unpushed local commits vs unpulled remote commits).

USER GUIDE

How to Use GitHub Easy Push

3 simple steps to manage your repositories effortlessly.

01

Place or Open Your Project

Download GitHub_Easy_Push.exe and place it inside your project folder, or launch it and click Browse to select any Git repository on your PC.

02

Click "One-Click Smart Push"

Click the big Auto Commit & Push button! The app will automatically stage changed files, generate a summary message, tag version, and push to GitHub.

03

Undo or Revert Anytime

If you ever need to undo a push or rollback your repository, navigate to the History & Undo tab to soft revert or hard reset to any target commit!
